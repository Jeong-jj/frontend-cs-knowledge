# 세션 시작

**정답을 먼저 주지 않는다.** 이 스킬의 마지막 단계는 질문을 던지고 멈추는 것이다.

## 1. 진도를 읽는다

```bash
cat sessions/progress.md 2>/dev/null || echo "없음"
```

없으면 만든다.

```bash
mkdir -p sessions && cp docs/progress-template.md sessions/progress.md
```

이 경우는 **새 학습자다.** 회차를 1회독으로 두고 오늘 날짜를 시작일로 적는다.
**저장소에 문서가 이미 채워져 있어도 진도는 백지다.** 문서 완성과 학습 진도는 다른 축이다.

있으면 회차, 주제별 상태, 막힌 횟수, 다음 복습 대상을 파악한다.

## 2. 복습 대상을 먼저 꺼낸다

「다음 복습 대상」 과 「막힌 지점」 을 본다.
**대상이 있으면 새 주제보다 먼저 제안한다.**

> 오늘 시작 전에 `microtask 가 렌더링보다 먼저인 이유` 를 5분 복습하는 것을 권합니다. `/drill` 로 진행할까요?

복습에 별도 시간을 쓰지 않는다. 세션 앞 5~10분이다.

## 3. 오늘 주제를 정한다

### 인자가 있으면

그 주제로 한다. **다만 진도 포인터를 옮기지 않는다.**

인자는 이번 세션에서 다룰 주제일 뿐이다. 순서를 벗어나 5주차를 먼저 해도
2주차가 `미학습` 이면 그대로 둔다. 옮기면 건너뛴 주차가 조용히 사라진다.
순서를 벗어난 것은 세션 기록에만 남긴다.

### 인자가 없으면

주제별 상태 표에서 **위에서부터 첫 번째 `미학습` 행**이 오늘 주제다.
`학습중` 이 있으면 그것을 먼저 끝낸다.

### 전부 `학습완료` 면

한 바퀴를 돈 것이다. **다음 회차를 물어본다.**

> 8개 주제를 모두 학습했습니다. 2회독을 시작할까요?
> 시작하면 주제별 상태를 미학습으로 리셋하고 완료 회차를 1씩 올립니다.

승인받으면 「회차」 표에 줄을 추가하고(이전 회차의 종료일을 오늘로 채운다),
주제별 상태를 전부 `미학습` 으로 되돌리며 완료 회차를 올린다.
**막힌 횟수는 리셋하지 않는다.** 회차를 가로질러 누적되어야 약점이 드러난다.

2회독 이후에는 막힌 횟수가 높은 주제부터 시작할 것을 권한다.

## 4. 세션 파일을 만든다

```bash
cp docs/session-template.md sessions/$(date +%Y-%m-%d)-<주제>.md
```

이미 있으면 이어 쓴다. 짧게 확인한다.

- 오늘 다룰 주제와 회차
- 이전 학습 중 연결되는 개념
- 이번 세션의 완료 기준

## 5. 진단 질문을 던진다

`docs/study-guide.md` 의 해당 주차 「대표 질문」 에서 **2~3개**를 고른다.
2회독 이상이면 **1회독 때와 같은 질문을 쓴다.** 그래야 첫 답변과 비교된다.

**해당 문서가 이미 채워져 있으면, 열지 말라고 먼저 말한다.**
읽고 나면 아는 것과 방금 읽은 것을 구분할 수 없다.

**여기서 멈춘다.** 설명하지 않고, 힌트를 주지 않고, 답을 암시하지 않는다.

> 검색하거나 자료를 보기 전에, 지금 아는 만큼만 답해 주세요. 이 답변은 평가가 아니라 출발점입니다.

## 6. 답변을 받은 뒤

**맞은 것 / 빠진 것 / 잘못된 것** 으로 나눠 피드백하고
`CLAUDE.md` 의 학습 사이클 2단계로 넘어간다.

### 문서가 비어 있으면

1회독 흐름이다. 개념을 설명하고, 재현하고, 학습자가 설명하고, 문서를 만든다.

### 문서가 이미 채워져 있으면

문서를 **출발점**으로 삼는다. 매번 처음부터 찾지 않아도 되고, 이전 회차의 정리가 쓰인다.

다만 **유일한 출처로 삼지 않는다.**

- 문서에 없는데 이 주제에 중요한 것이 있으면 짚는다. → **문서 결함**
- 문서에 있어도 근거가 불확실하면 검증 TODO 로 내린다. → **문서 결함**
- 학습자가 막힌 것이 문서에는 제대로 있으면 그것은 학습자의 몫이다. → **막힌 지점**

이 둘을 섞지 않는다. 앞은 문서를 고칠 대상이고 뒤는 복습할 대상이다.

**문서를 읽는 것이 학습을 대체하지 않는다.** 학습자가 자기 말로 다시 설명하는
4단계는 문서가 있어도 건너뛰지 않는다. 건너뛰면 회독이 재독이 된다.
